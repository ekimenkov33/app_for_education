# Образовательное приложение на PyQt5

## Описание проекта

Приложение предоставляет пользователю доступ к теоретическим материалам по программированию и возможность проходить тестовые задания. Основная задача проекта — объединить изучение и практику в интуитивно понятном десктопном приложении, которое работает локально и не требует подключения к интернету. Приложение стабильно функционирует на операционных системах Windows и Linux, а его интерфейс корректно адаптируется под разные разрешения экрана.

## Технологии

* **Язык программирования:** Python.


* **Графический интерфейс (GUI):** PyQt5 — кроссплатформенный инструмент для построения интерфейсов. (В процессе выбора также рассматривались Tkinter, Kivy, Electron и JavaFX).


* **База данных:** SQLite — используется для локального хранения данных пользователей и результатов без необходимости установки отдельного сервера.



## Основной функционал

* **Модуль регистрации и входа:** Отдельное окно авторизации для пользователей.


* **Учебные материалы:** Вкладки с теоретическими блоками по Python, JavaScript и CSS/HTML. Содержимое загружается из встроенных HTML-блоков, поддерживается прокрутка, заголовки и подсветка кода.


* **Викторина:** Тестирование знаний с таймером и системой подсчета баллов.


* **Личный кабинет:** Профиль, в котором отображаются имя пользователя, логин и лучший сохраненный результат.



## Алгоритм работы

1. **Запуск:** Открывается окно входа или регистрации.


2. **Главное окно:** После успешной авторизации открывается основное окно с навигационными вкладками.


3. **Изучение:** Пользователь изучает теорию по выбранному языку программирования.


4. **Викторина:** Пользователь отвечает на вопросы на время и зарабатывает баллы.


5. **Результаты:** По завершении итоги сохраняются в базу данных и выводятся на экран.


6. **Личный кабинет:** Пользователь может просмотреть свою статистику.



## Структура кода

* `LoginDialog` — класс для реализации регистрации и авторизации.


* `StudyApp` — основной класс, отвечающий за реализацию вкладок, интерфейса, логики викторины и профиля.


* Для работы с базой данных применяется встроенная библиотека `sqlite3`.


* Активно используются элементы PyQt5: `QTimer`, `QLabel`, `QTextEdit`, `QPushButton`, `QRadioButton` и другие.
